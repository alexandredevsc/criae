# CrIAê

> Sua ideia, seu prompt, sua criação.

Plataforma educativa para estudantes e iniciantes aprenderem a usar inteligência artificial generativa por meio de conteúdos, atividades e experiências práticas.

## Objetivo

Ensinar o aluno a criar e melhorar prompts, analisar os resultados e utilizar IA com responsabilidade.

## Status

Em desenvolvimento. A estrutura inicial em React está criada. As funcionalidades abaixo ainda serão implementadas. 

## Funcionalidades planejadas

- Cadastro, login e recuperação de senha.
- Trilhas de aprendizagem sobre IA generativa.
- Desafios com feedback e pontuação.
- Laboratório de prompts com geração de texto e imagem.
- Tutor com IA.
- Progresso individual por aluno.
- Temas claro e escuro.
- Interface responsiva e instalação como PWA.

A geração de vídeo será avaliada conforme acesso, custo e prazo.

## Tecnologias iniciais

- React com JavaScript
- Vite
- CSS
- ESLint
- Git e GitHub

## Como executar

Pré-requisito: Node.js compatível com a versão do Vite utilizado.

Instale as dependências:

    npm install

Inicie o servidor de desenvolvimento

    npm run dev

Abra o endereço informado no terminal.

## Organização inicial

- src/components: componentes reutilizáveis.
- src/pages: telas da aplicação.
- src/styles: estilos e temas.
- src/data: conteúdos educativos e perguntas.
- src/hooks: lógicas React reutilizáveis.
- src/services: comunicação com serviços.
- src/contexts: estado compartilhado.
- src/assets: recursos utilizados pela interface.
- docs/referencias: referências visuais do projeto.
